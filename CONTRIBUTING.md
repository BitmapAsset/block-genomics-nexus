# Contributing to Block Genomics Nexus

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b feat/your-feature`
3. Make your changes
4. Run `npx next build` — must pass cleanly
5. Open a Pull Request against `main`

## Code Style

- **TypeScript** — strict mode, no `any`
- **Next.js 16** App Router conventions
- Prefer server components; use `"use client"` only when necessary
- Name files in kebab-case, components in PascalCase

## Pull Requests

- Keep PRs focused and small
- Write a clear description of what and why
- Reference related issues
- All CI checks must pass

## Security

**Do not open public issues for security vulnerabilities.**

Email security reports to **security@blockgenomics.io** with details and reproduction steps. We will respond within 48 hours.

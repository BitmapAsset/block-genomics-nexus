Embed Methods

Multiple ways to add Block Genomics badges to your project.

📝 HTML Embed

Copy-paste into any website.

<img src=".../badge/ID">

📜 JavaScript Widget

Auto-renders with live data.

<script data-genome="ID">

⚛️ React Component

For Next.js / React apps.

<BlockGenomicsBadge />

📋 Markdown Badge

For GitHub READMEs.

[![Verified](badge-url)](link)

🔗 Direct URL

Link directly to the SVG.

GET /api/v1/badge/{id}

🤖 API Verification

Programmatic verification.

GET /api/v1/verify/{id}

HTML Image Embed

HTML <!-- Block Genomics Verification Badge --> <a href="https://verify.blockgenomics.io/agent/bg_a3f7b2c1d4e5f6a7" target="_blank" rel="noopener"> <img src="https://verify.blockgenomics.io/api/v1/badge/bg_a3f7b2c1d4e5f6a7?style=standard" alt="✓ Verified by Block Genomics" width="360" height="80" /> </a>

JavaScript Widget (Recommended)

HTML <!-- Drop this anywhere in your HTML --> <script src="https://cdn.blockgenomics.io/embed.js" data-genome="bg_a3f7b2c1d4e5f6a7" data-style="standard" data-theme="dark"></script>

React Component

TSX import { BlockGenomicsBadge } from '@blockgenomics/react-badge'; // Fetch by genome ID <BlockGenomicsBadge genomeId="bg_a3f7b2c1d4e5f6a7" style="standard" theme="dark" /> // Or pass agent data directly <BlockGenomicsBadge agent={agentData} style="detailed" />

Markdown (GitHub README)

Markdown [![Block Genomics Verified](https://verify.blockgenomics.io/api/v1/badge/bg_a3f7b2c1d4e5f6a7?style=minimal)](https://verify.blockgenomics.io/agent/bg_a3f7b2c1d4e5f6a7)

JavaScript API

JavaScript // After loading embed.js, use the global API: // Render into a target element BGB.render('bg_a3f7b2c1d4e5f6a7', document.getElementById('badge-target'), { style: 'standard', theme: 'dark', animate: true }); // Or render from existing data (no API call) BGB.renderSync(agentData, targetElement, { style: 'detailed' }); // Get raw SVG string const svg = BGB.svg(agentData, { style: 'minimal', theme: 'light' });

# 🐸 Pepe Command Center v2

> Mission Control for Gravity — track projects, tasks, timelines, and files.

## Quick Access

| Method | How |
|--------|-----|
| **Browser** | [http://localhost:8099](http://localhost:8099) |
| **Mac App** | Search "Pepe Command Center" in Spotlight, or find it in `/Applications` |
| **Terminal** | `./start.sh` |

## Features

- **📊 Overview** — Stats, active projects, recent activity at a glance
- **📂 Projects** — Click to drill down into tasks, workflow tables, progress rings
- **📅 Timeline** — Chronological view of milestones and events
- **🗄️ File Inventory** — Browse project file structure
- **🔍 Search** — Filter projects and tasks (or press `/`)
- **🏷️ Filters** — Filter by status (Active/Planning/Complete) or priority (Critical)

## Architecture

```
command-center/
├── index.html         # Main dashboard (single-file, all CSS/JS embedded)
├── server.js          # HTTP server (port 8099)
├── scan-files.js      # File inventory scanner
├── start.sh           # Quick launcher
├── README.md          # This file
└── electron-app/      # Mac native app wrapper
    ├── main.js        # Electron main process
    ├── package.json   # App config
    └── dist/          # Built .app
```

## Data

Dashboard reads from `../dashboard-data.json` (same dir as all projects).
File inventory is generated by `scan-files.js` → `../file-inventory.json`.

## Auto-Start

A LaunchAgent (`com.pepe.command-center`) keeps the server running.
The server auto-starts on login and stays alive.

## Modifying

Everything is in `index.html` — CSS, JS, HTML all in one file for easy editing.
Change the styles, add new views, update the layout — it's all there.

The data format in `dashboard-data.json` is the source of truth. Update that file
and the dashboard auto-refreshes every 30 seconds.

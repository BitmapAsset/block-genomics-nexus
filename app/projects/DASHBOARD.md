## 📁 Project Structure

Each project gets its own folder in `/projects/`:
```
/projects/
  DASHBOARD.md          ← You are here
  project-name/
    README.md           ← Project overview, goals, status
    tasks.md            ← Detailed task breakdown
    notes.md            ← Research, decisions, learnings
    logs/               ← Session logs specific to project
```

---

## 🔄 How to Use This Dashboard

**Adding a project:**
1. Create folder: `/projects/project-name/`
2. Add README.md with overview
3. Update this dashboard

**Updating status:**
- 🟢 Active — Currently working on
- 🟡 Paused — On hold, will resume
- 🔴 Blocked — Waiting on something
- ✅ Complete — Done!

**Priority levels:**
- 🔥 Critical — Do now
- ⬆️ High — This week
- ➡️ Medium — Soon
- ⬇️ Low — When time permits

# PDF Genius — AI-Powered PDF Tools

## Vision
Free PDF tool suite with AI superpowers. Monetized via AdSense + premium tier.
Completely separate from Block Genomics — different GitHub, Vercel, identity.

## Domain (pending)
pdfgenius.io (preferred) — Gravity to register on wake

## Tech Stack
- Next.js 15 (App Router)
- Tailwind CSS
- pdf-lib (client-side PDF manipulation — files never leave browser)
- PDF.js (Mozilla's PDF renderer)
- OpenAI API (for AI features — summarize, chat, translate)
- Vercel deployment
- Google AdSense

## MVP Tools (Phase 1 — 10 tools)

### Core PDF Tools (browser-side, zero upload)
1. **Merge PDF** — combine multiple PDFs into one
2. **Split PDF** — extract pages or split into chunks
3. **Compress PDF** — reduce file size
4. **PDF to Image** — convert pages to JPG/PNG
5. **Image to PDF** — convert images to PDF
6. **Rotate PDF** — rotate pages
7. **Add Page Numbers** — stamp page numbers
8. **Watermark PDF** — add text/image watermark

### AI-Powered Tools (our edge)
9. **AI Summarize PDF** — upload PDF, get instant summary
10. **Ask Your PDF** — chat with any PDF document

## Key Differentiators
- 🔒 **Privacy-first**: All core tools run IN THE BROWSER. Files never touch our servers.
- 🤖 **AI features**: Nobody else combines PDF tools + AI chat/summarize
- ⚡ **No limits on free tier**: Unlimited usage, ad-supported
- 🎨 **Modern UI**: Clean, fast, beautiful — not the 2015 look of competitors

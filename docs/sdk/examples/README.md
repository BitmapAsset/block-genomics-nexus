# SDK Examples

These examples are starter files for external builders. They are renderer-neutral and can be adapted to Three.js, React Three Fiber, Unity, Unreal, Godot, voxel clients, or agent simulation runtimes.

- [world-builder.ts](world-builder.ts) - TypeScript client for verifying ownership, building signed mutation messages, and reading or mutating world state.

The examples assume the caller already has a Bitcoin wallet adapter capable of signing a message.

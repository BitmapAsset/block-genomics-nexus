# 🧬 Block Genomics — Decode the DNA of Bitcoin

> The trust layer for AI Agents. Built on Bitcoin. Powered by Bitmap.

## Vision
In a world of billions of AI agents, trust is everything. Block Genomics uses Bitcoin block ownership (Bitmap) to create unforgeable, meaningful identity and verification for autonomous agents.

## Products
1. **Block Genomics Explorer** — Visualize the DNA of any Bitcoin block (`/index.html`)
2. **Block Genomics Verify** — AI Agent verification protocol & badges (`/verify/index.html`)
